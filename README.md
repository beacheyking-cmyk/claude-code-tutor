# Claude Code Tutor

Turn Claude Code into a coding tutor — any language, beginner to Super Coder.

## Quick Start

Install Claude Code, clone this repo, run claude, then type /start.

## Slash Commands

- /start — Onboarding
- /quiz — Pop quiz NOW
- /hint — Nudge without answer
- /solution — Full solution
- /challenge — Boss challenge 50 XP
- /level — Stats and XP
- /review — Redo lesson
- /weak — Weak topics
- /roadmap — Full curriculum

## Ranks

Egg > Hatchling > Coder > Developer > Engineer > Super Coder
