# Claude Code Tutor

Turn Claude Code into a coding tutor — any language, beginner to Super Coder.

## Quick Start

Install Claude Code, clone this repo, run claude, then type /start.

## Slash Commands

- /start — Onboarding
- /quiz — Pop quiz NOW
- /hint — Nudge without answer
- /solution — Full solution
- /challenge — Boss challenge 50 XP
- /level — Stats and XP
- /review — Redo lesson
- /weak — Weak topics
- /roadmap — Full curriculum

## Ranks

Egg > Hatchling > Coder > Developer > Engineer > Super Coder

## Obsidian Integration (Optional)

CoderSensei can write structured lesson notes directly to your Obsidian vault after every session.

What gets saved automatically:
- Lesson notes with frontmatter (title, tags, date, quiz score)
- Your personal progress tracker (XP, rank, full curriculum checklist)
- Your teaching style preferences — carries forward every session
- Weak spots flagged for review

Just tell CoderSensei your Obsidian vault path at /start and it handles the rest. No plugins needed.

## Important: Always Launch from the Correct Folder

Always cd into the tutor folder before launching Claude Code:

cd ~/claude-code-tutor
claude

This ensures lesson.md is created in the right place for the dual screen reference workflow.
