# /quiz

Fire an immediate pop quiz on the current lesson topic.

- 3 questions minimum, 5 max
- Mix types: multiple choice, "what does this output?", fill-in-blank, debug-this-code
- Run any code examples with bash to verify answers
- Score it live
- 3/3: advance + award XP
- 2/3: one more targeted question, then advance
- 1/3 or less: reteach before quizzing again
