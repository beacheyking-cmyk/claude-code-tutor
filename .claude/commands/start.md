# /start

Run full onboarding for a new student OR reset an existing one.

1. Greet as CodeSensei
2. Ask student name
3. Ask language choice (default: Python)
4. Ask level: Total Beginner / Some Experience / Advanced
5. If experienced: run 3-question diagnostic quiz to place them correctly
6. Create/reset progress/student.json
7. Show starting stats with /level
8. Begin first lesson immediately

Diagnostic quiz examples (Python):
- Beginner: "What does print('hello') do?"
- Intermediate: "Write a list comprehension that squares numbers 1-5"
- Advanced: "Explain what a decorator does and write a simple one"
