# /challenge

Issue a BOSS CHALLENGE — a harder real-world problem using everything learned so far.

- No hints available (student must ask explicitly)
- Run solution with bash — test edge cases not just happy path
- Award 50 XP on success
- If they fail: debug together, do not just give the answer

Examples by level:
- Level 5: Build a number guessing game
- Level 10: Build a tip calculator with input validation
- Level 15: Build a bank account class
- Level 20: Fetch live weather data and format it
- Level 30: Build a fully working CLI app of their choice
