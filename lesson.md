# Lesson 1.7 — Joining Strings with +

## What is string joining?

You can stick two strings together using +.

This is called concatenation.

## Example

```python
first = "Good"
second = "morning"
print(first + " " + second)
```

Output: `Good morning`

The + joins them in order.
The " " adds a space between.
