# Lesson 1.8 — .count()

## What it does
.count() counts how many times a letter or word appears in a string.

## Example
```python
word = "banana"
print(word.count("a"))
```
Output: `3`

There are 3 a's in "banana".

## Another example
```python
sentence = "the cat sat on the mat"
print(sentence.count("the"))
```
Output: `2`
